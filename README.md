# Zhang Yi — Academic Homepage

Source files for a concise bilingual academic homepage linking three research lines:

1. inclusive educational environments;
2. place-based spatial transformation;
3. spatial evidence and decision methods.

The site uses plain HTML and CSS, with no framework, analytics, external font service, or content-management system.
